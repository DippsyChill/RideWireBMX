# RideWireBMX

Responsive static homepage for RideWireBMX.

## Run locally

Open `index.html` in a browser. The site has no build step or package dependencies.

## Publish on IONOS

Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the website's document root in IONOS Webspace. Keep the files in this structure so the stylesheet, script, and hero image paths resolve. The site's entry page is `index.html`.

The current site is frontend-only. It does not require a backend, database, or server-side runtime.
